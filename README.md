# Task 01 - GPT-2 Text Generation

## Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- GPT-2

## How to Run

### 1. Activate virtual environment

Run this command in Terminal:

source venv/bin/activate

### 2. Install dependencies

Run this command in Terminal:

pip install -r requirements.txt

### 3. Run the program

Run this command in Terminal:

python text_generation.py

## Project Description

This project uses the GPT-2 language model to generate text based on a user-provided prompt.

The program provides an interactive command-line interface and allows the user to enter multiple prompts.
